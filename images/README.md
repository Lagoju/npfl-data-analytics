
# Images

This directory contains screenshots of the Power BI report developed for the NPFL Data Analytics project.

## Contents

The screenshots provide a visual overview of the completed Power BI report, covering the project's main analytical areas:

- NPFL Six Season league performance
- Club performance and home advantage 
- Geography, population and club success
- League competitiveness and club trends
- Player performance and goal contributions
- Stadium and match environment

The screenshots are included to provide a quick visual reference for the final analytical report and to demonstrate the presentation and visualisation layer of the project.

## Purpose

The images complement the underlying analytical work contained in the `python/`, `sql/` and `power_bi/` directories.

They allow the report's outputs to be reviewed without requiring access to the original licensed dataset.

> **Note:** The screenshots are outputs of the Power BI analysis and do not constitute the underlying source data. The commercial football datasets used to produce the report are not redistributed in this repository.
