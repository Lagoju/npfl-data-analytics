# Key Insights

This directory contains the key findings, conclusions and strategic recommendations produced from the NPFL Data Analytics project.

## Contents

The primary deliverable in this directory is the project's PowerPoint presentation:

**NPFL Performance Analysis**

The presentation brings together the results from the project's SQL, Python and Power BI analysis into a single analytical narrative.

It covers:

- Background of Nigerian professional football and the NPFL
- Dataset scope and analytical methodology
- The relationship between population and club performance
- Geographic and geopolitical differences in club performance
- NPFL league competitiveness across six seasons
- Sustained club success and performance trends
- Home advantage and match outcomes
- Player scoring performance and goal contribution
- Stadium utilisation and match environment
- Comparison of the NPFL with leading global football leagues
- Strengths and weaknesses of the NPFL
- Recommendations for improving the league's sporting, data, broadcast, infrastructure and commercial ecosystem

## Purpose

The `key_insights/` directory represents the final **"so what?"** stage of the project.

While the `python/`, `sql/` and `power_bi/` directories demonstrate how the analysis was performed, this directory focuses on what the analysis revealed and how those findings can inform decisions and recommendations.

The presentation therefore connects the technical analysis to a broader business and sporting context.

## Key analytical conclusions

Among the main findings from the project:

- Population size alone does not show a statistically significant relationship with club performance.
- League competitiveness improved across the six-season period, with the PPG spread decreasing substantially.
- Home advantage is a strong characteristic of the NPFL, with home teams achieving considerably higher points per game than away teams.
- Sustained success is concentrated among a smaller group of consistently high-performing clubs.
- Player goal contribution is concentrated primarily among forwards.
- Stadium environments show meaningful differences in match activity and goal patterns.
- The analysis suggests that the NPFL's larger opportunity is not simply increasing football participation, but strengthening the systems that convert football talent and audience interest into sustainable sporting and commercial value.

## Important analytical considerations

The findings should be interpreted alongside the project's documented data limitations, including:

- The nonexistence of league level data
- Dependence on somewhat incomplete third party data 
- The abridged 2022/23 season
- Duplicate player records
- Missing stadium information for some matches
- Geographic mapping limitations
- Incomplete advanced player statistics
- xG model calibration considerations

These limitations are discussed in greater detail within the presentation and supporting project documentation.
